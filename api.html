empty.string API

One small JavaScript interface, hourly JSON feeds and an embeddable player for free, legal music: full songs, DJ mixes, live radio, podcasts, concerts and world charts. No account, no key, no server. Every request goes straight to the original source.

Quick start

Add one script tag

<script src="https://femboyss.github.io/empty-strings/api/empty-string.js"></script>
<script>
  const songs = await EmptyString.search('lofi');           // full songs (Audius + hearthis.at)
  EmptyString.play(songs[0]);                               // plays it with a built-in <audio>

  const radio = await EmptyString.radio({ country: 'AT' }); // live stations in Austria
  const pods  = await EmptyString.podcasts.hot({ lang: 'de' });
</script>

Works in any modern browser and in Node 18+ (require('./empty-string.js')). All sources send CORS headers, so it runs on any website, including GitHub Pages.

Result format

Every result looks the same

{
  "id": "audius:a5aXGmz",
  "source": "audius",          // audius | archive | hearthis | mixcloud | radio-browser | fyyd | listenbrainz | itunes | youtube | soundcloud | link
  "kind": "track",             // track | station | episode | album | podcast
  "title": "Return",
  "artist": "nazah",
  "artwork": "https://...jpg",
  "duration": 214,             // seconds, 0 if unknown or live
  "stream": "https://...",     // direct https audio, or null
  "embed": null,               // official player URL (Mixcloud, YouTube, SoundCloud) when there is no direct stream
  "link": "https://audius.co/...",
  "live": false,
  "license": ""
}

If stream is set, play it in an <audio> element. If only embed is set, put it in an <iframe allow="autoplay">. Those sources only allow playback in their own player.

Reference

Methods

MethodReturns
search(q, {sources, limit})Results from the chosen sources. Default ['audius','hearthis']; also mixcloud, archive, radio-browser, fyyd.
trending({genre, time})Trending full songs on Audius. Genres like Electronic, Hip-Hop/Rap, Lo-Fi.
radio({country, tag, near, limit, order})Live stations. near: {lat, lon, km} finds stations around a point.
archive.search(q, {collection})Albums from the Internet Archive. Collections: netlabels, concerts, 78rpm, mixtapes, oldtimeradio, audiobooks.
archive.album(id)All playable tracks of an Archive item, with license.
mixes.hearthis(type) / mixes.mixcloud(tag)Full tracks and DJ mixes (hearthis: popular, new). Mixcloud results come with embed.
podcasts.hot({lang}), podcasts.search(q), podcasts.episodes(id)Podcasts and full episodes from fyyd.
charts({range})World charts from real listens (ListenBrainz): week, month, year. Metadata only.
findPlayable({title, artist})A free full version on Audius, else the official 30 s iTunes preview, else null.
resolve(link)Turns YouTube, SoundCloud, Mixcloud, Audius or direct https audio links into a result.
lyrics({title, artist, duration})Lyrics from LRCLIB, synced when available.
embedUrl(result or link)URL of a ready-made iframe player for that result.
play(result) / pause()Tiny built-in player for results with a stream.
No code needed

JSON feeds

Pre-built lists, refreshed every hour by a GitHub Action. Plain JSON with CORS, so any app, bot or website can read them. The index lists all feeds with their last update.

Embed player

Drop a player for any song, station or link into your page.

<!-- any supported link -->
<iframe src="https://femboyss.github.io/empty-strings/embed.html?url=https%3A%2F%2Fsoundcloud.com%2Fforss%2Fflickermood"
        width="100%" height="122" allow="autoplay" style="border:0"></iframe>

<!-- item 0 of a JSON feed -->
<iframe src="https://femboyss.github.io/empty-strings/embed.html?feed=trending&i=0"
        width="100%" height="122" style="border:0"></iframe>

Sources and rules

empty.string only uses public endpoints that are meant to be called from browsers. When you build on it, follow each source's own rules:

SourceNotes
AudiusRequests carry app_name=empty.string. Only streamable, ungated tracks are returned.
Internet ArchiveCheck each item's license (often Creative Commons). Keep request volume reasonable.
Radio BrowserCommunity database; streams belong to the broadcasters. Several mirrors are used.
hearthis.atLink back to the track page when you show a track.
MixcloudPlayback only in the official widget (embed).
fyydPodcast audio comes from the publishers' own servers.
ListenBrainz / Cover Art ArchiveOpen data from MetaBrainz. Charts are metadata only.
iTunes SearchOnly official 30 s previews, rate limited (about 20 requests per minute).
LRCLIBCommunity lyrics database.

Not included on purpose: services that need a secret key in the browser, block cross-site requests, or protect their streams against embedding.
